# Task: provider cloud per LLM e trascrizione

Piano: `specs/003-cloud-providers/plan.md` v1.0 (citato come "C<n>", "R<n>", "Dis.<n>"); decisioni
in `adr.md` (ADR-003, "A<n>") e decisioni dell'utente "D1-D4" (non riaprire). Ogni task è TDD:
test rosso prima, poi verde. Comandi via `uv run`. Mock solo ai boundary: provider via
`httpx.MockTransport` o fake `ChatClient`, Ollama via `ollama_chat`, orologio e `sleep` iniettati,
processi figli; filesystem reale su `tmp_path`. **Nessuna chiamata di rete reale nei test**: una
fixture `autouse` in `tests/conftest.py` fa fallire ogni trasporto httpx non mockato. Chiavi nei
test: solo sentinelle (`sk-SENTINEL-...`). Regole: funzioni ≤ 30 righe, file ≤ 300 (i file già
oltre non crescono), max 4 parametri, keyword arguments, pathlib, `encoding="utf-8"`. Ogni
dettaglio di API dei provider è UNVERIFIED finché T010/T050 non l'hanno confermato in `adr.md`.

Legenda Delega: **[C]** Codex via `tdd-guide` (logica pura, adapter) o `senior-backend` (API,
persistenza, wiring); **[UI]** `fullstack-developer` in-house; **[M]** verifica o misura non
delegabile; **[G]** gate di fase, orchestratore. Blocchi **[B-n]** = 2-4 task per invocazione.
Agent paralleli: un worktree per agent. Nessun task tocca `data/` reale.
