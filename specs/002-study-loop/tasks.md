# Task: ciclo di studio (frasi d'esame, ripasso, esercitazioni, formule, pacchetto corso)

Piano: `specs/002-study-loop/plan.md` v1.2 (citato come "C<n>", "U<n>", "R<n>"); decisioni in
`adr.md` (ADR-002, "D<n>", verifiche "V<n>"). Ogni task è TDD: test rosso prima, poi verde.
Comandi via `uv run`. Mock solo ai boundary (Ollama via `ollama_chat`, orologio, processi figli);
filesystem reale su `tmp_path`, SQLite reale. Regole: funzioni ≤ 30 righe, file ≤ 300 (i file già
oltre non crescono), max 4 parametri, keyword arguments, pathlib, `encoding="utf-8"`. Dopo ogni
`uv add`: `uv sync --extra cuda`.

Legenda Delega: **[C]** Codex via `tdd-guide` (logica pura) o `senior-backend` (API,
persistenza); **[UI]** `fullstack-developer` in-house; **[M]** misura o etichetta, non delegabile;
**[G]** gate di fase, orchestratore. Blocchi **[B-n]** = 2-4 task per invocazione. Agent paralleli:
un worktree per agent. Nessun task tocca `data/` finché il job in corso non è chiuso; T015 legge
`data/jobs/` in sola lettura e scrive solo `data/eval/`.
La colonna Req. cita anche le verifiche dell'ADR coperte: a fine fase i loro esiti vanno in
`adr.md` § Verifiche.
